______STAGE 1_______

Instructions to Check and Use

1. Open the 'test_folder' document and upload the notebook on Google Collab
2. Upload all the files in '/test_folder/documents_to_upload_before' to Google Collab
3. Change the run time configuration on Google Collab to 'GPU' [ Runtime -> Change Runtime Type ]
4. Run all command on the notebook


Directory Structure

1. /scripts - contains scripts which we have used to scrape the web and generate synonyms and cefr level .csv files, 
	      scripts to convert .csv to .json, outdates .py files (will be updated shortly)
2. /data_files - contains all the files generated by the script and pdf folder containing all the PDF we have tested against

3. /test_folder - Notebook and the files to upload on Google Collab

4. /ppt - Power Point Presentation


Limitation:

* Updated Code runs on Google Collab only
* To run on Jypter Notebook - > Find the file "SentenceTransformer('roberta-base-nli-stsb-mean-tokens',device="cuda")" under SemanticCheck
  class and place with the following line "SentenceTransformer('roberta-base-nli-stsb-mean-tokens')"

Workflow:

* Local (Enabled by default) - Opens a dummy html page to upload a pdf, converts and write back a pdf to the root folder with 'filename_reduced'
as the new filename. Creates a json file under the name 'json_data.json'

* Run with AngularJs - Uncomment the line "app.run()". Change the ngrok URL in the angular File and run the Html file Locally. Book can be uploaded,
Book will be parsed and a new UI page would be shown with the changed words highlighted in yellow.





______STAGE 2_______ [Latest Update]

Instructions to Use:

1. By running the train.py in /scripts/cefr_prediction_model/ the script would trigger training of 2 NN models along with their weights and 2 Random Forest Classifiers.
   The resultant of the solution would be training models and a graph to depict the training vs validation set accuracy along with their loss curves
2. test.py under /scripts/cefr_prediction_model can be run by specifying the 'word' and 'pos'. The resultant would be the CEFR level of the specified word. As of now result
   of Random Forest classifier is returned and is not combined with the result of NN model


Other Important Scripts:

1. google_ngram_parser.py under /scripts can be used to parse the Google N-gram viewer. Start year and end Year can be specified to the API and an array of values are returned in response
2. generate_ngram_data_for_cefr_master.py under /scripts can be used to scrape the 7620 words in the master_cefr file

3. all_english_words.json under /data_files can be used to get nearly ~300,000 words in english language
4. all_english_words_tagged.csv under /data_files can be used to view the tagging of the above 300,000 English words. Note: Tagging has been done using the nltk pos tagger using the 'average_perceptron_tagger'
5. master_ceft_with_ngram under /data_files has the ngram data from 2013-2019 for 7620 words along with their Part of Speech
